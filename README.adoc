# FinTS-Cli
Eine App für die Kommandozeile, um Kontostände und Transaktionen über FinTS abzufragen
:toc:
:toc-title: Inhaltsverzeichnis
:toclevels: 5

Mit dieser App für die Kommandozeile kann man von Kontostände und Transaktionen von Deutschen 
Banken über FinTS abfragen.

WARNING: Diese App ist eigentlich nur für meine persönlichen Zwecke, könnte aber
auch für andere nützlich sein. Mit Nutzung dieser App, erklärt sich der 
Nutzer damit einverstanden, dass es **sein persönliches Risiko** ist und 
**ich nicht hafte**.

Bisher funktioniert die Abfrage bei meinem Postbank-Depot und bei meinem Postbank-Anlagekonto.
Bei meinem Postbank-Girokonto funktioniert es dagegen nicht. Bei der DKB ist zwingend eine
Produktregistrierung erforderlich siehe https://www.fints.org/de/hersteller/produktregistrierung.



## Benutzung während der Entwicklung

Man kann eine 'config.yaml' anlegen mit den aus link:config.yaml.example[] ersichtlichen Variablen.
Oder man nutzt die Optionen auf der Kommandozeile.

```bash
  dart run bin/fints_cli.dart --help
```

Mit dem Paket https://jqlang.org/manual/[jq] und der Kommandozeilenoption `--quiet` kann man sich die 
Transaktionen schön anzeigen lassen oder weiterbearbeiten.

```bash
  dart run bin/fints_cli.dart --account extra  --transaction_format mt940 --quiet --last_days 5 | jq .
```
